# Security Policy

Do not open a public issue for credentials, request/response bodies, private repository paths, or a vulnerability that could expose them.

Report security issues privately to the repository owner through GitHub security advisories or a private GitHub contact channel. Include a minimal reproduction with all secrets and personal data removed.

This project intentionally stores only bounded, redacted run metadata. Please report any case where task text, credentials, raw model output, or local file contents are persisted or emitted unexpectedly.
